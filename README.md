#  Motor Predictive Maintenance

Built an end-to-end predictive maintenance pipeline to detect bearing faults in electric motors. By applying Fast Fourier Transform (FFT) signal processing and extracting statistical markers from raw vibration data, this project uses a Random Forest machine learning model to spot mechanical failures. It includes a Streamlit web app for instant diagnostics.

##  Tech Stack
* **Language:** Python
* **Data & Signal Processing:** `numpy`, `scipy`, `pandas`
* **Machine Learning:** `scikit-learn` (Random Forest Classifier)
* **Visualization:** `matplotlib`
* **Web UI:** `streamlit`
* **Dataset:** [CWRU Bearing Data Center](https://engineering.case.edu/bearingdatacenter)
